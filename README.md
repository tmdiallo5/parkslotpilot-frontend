# ParkSlotPilot - Frontend (React)

Frontend application for ParkSlotPilot.

---

## Current Features

- Signup page
- Login page
- Account activation flow
- JWT authentication
- Protected routes
- Session persistence using sessionStorage

---

## Authentication Flow

- Signup → email activation
- Login → JWT stored in sessionStorage
- Access to protected pages
